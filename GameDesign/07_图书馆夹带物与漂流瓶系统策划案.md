# 图书馆夹带物与漂流瓶系统策划案 (深度系统耦合与高可玩性版)

## 1. 系统概述 (Overview)
本系统是《DieLoli》涌现式沙盒的核心玩法之一。它严格挂载于现有的 **效用AI状态机** 与 **Settle(结算器)** 管线中，无需调用外部大模型。
其核心游戏性（Playability）在于：将图书馆从单纯的“读书挂机加属性点”的场所，转变为一个**异步的情报黑市与社交操纵场**。玩家不仅可以**搜寻（Scavenge）**他人遗落的把柄与解谜残页，更可以**主动伪造（Plant）**纸条来干涉NPC间的关系网（Social Matrix），实现极度真实的校园暗流涌动。

## 2. 核心数据结构与配置 (Data & Configuration)

在 `Script/Core/game_type.py` 中拓展 `HiddenNote` 数据结构，以及配套的全局配置表。

### 2.1 内存数据结构
```python
class HiddenNote:
    """ 夹带物/漂流瓶 实例对象 """
    def __init__(self):
        self.uid: UUID = ""             # 实例唯一ID
        self.book_id: int = 0           # 所在的 Book ID (对应 config_book)
        self.owner_id: int = -1         # 留下物品的 NPC_ID (若是系统/玩家伪造则另作标记)
        self.config_id: int = -1        # 关联的预设文本配置表ID (对应 LibraryNoteConfig)
        self.type: int = 0              # 0:实物遗失, 1:情感日记, 2:解谜残页(Lore), 3:发泄涂鸦, 4:伪造的信件
        self.item_id: int = -1          # 若为实物(Type 0)，对应的Item ID
        self.target_id: int = -1        # 内容涉及的目标 NPC_ID（如情书写给谁）
        self.create_time: int = 0       # 留下的游戏时间戳 (用于生命周期控制)
        self.authenticity: bool = True  # 情报真实度 (联动 CharacterAwareness)
```

```python
self.library_hidden_notes: Dict[int, List[HiddenNote]] = {}
```

## 3. 核心机制设计 (Mechanics & Playability)

为强化可玩性，本系统由三大核心循环组成：**结算掉落(生成)**、**定点挖掘(获取)**、**伪造干涉(使用)**。

### 3.1 结算掉落机制 (Settle Drop) - NPC的无意识行为
夹带物不是NPC主动的行为目标，而是其行为的**副产物**。
1. **AI行为流转**：NPC执行 `Target_ReadBook` -> 进入状态机 `STATUS_READING` -> 完成或被打断触发 `settle_behavior.py` 中的 `handle_settle_behavior`。
2. **知识类别绑定 (Targeted Spawning)**：
   结算器不仅检查NPC状态，还会检查其**阅读书籍的属性**。例如，只有在阅读《黑魔法防御》等 `Mystics`（神秘学）相关书籍时，处于抑郁或被霸凌状态的NPC才有可能留下诅咒涂鸦（Type 3）。这要求玩家如果要查某个人的黑料，必须先了解其阅读偏好（Knowledge兴趣点）。
3. **取消系统自动清理 (No Automatic System Cleanup)**：
   系统不再按时间硬性销毁夹带物/漂流瓶。漂流瓶的生命周期将完全交由世界内NPC的自主行为决定，从而形成真实的生态流转。

### 3.2 玩家的定点挖掘 (Targeted Scavenging) - 高回报探索
玩家的日常探索分为两种策略：
*   **广撒网 (`[打扫书架]`)**：消耗大量体力和时间，在随机书籍中获得低级遗失物（如 `Item` 饭卡、硬币）或无意义碎碎念。
*   **尾随与推理 (`[检查刚被借阅的书]`)**：**高阶玩法**。玩家观察到高冷学生会长情绪低落（或者玩家故意去降低她的心情），尾随她去图书馆，等她读完某本书离开后，**立即**对该书执行检查。100%能够截获她处于极端情绪下的日记（获得决定性的把柄）。

### 3.3 伪造与社交干涉 (Planting & Manipulation) - 核心玩法升华
这是本作与其他文字游戏最大的区隔。夹带物不仅能被找到，还能被**制造**。
1. **伪造指令**：玩家可以通过指令 `[在书中夹入伪造信件]`。玩家选择一个 `target_id`（比如校花），伪造一封她写给不良少年的表白信（Type 4），夹在不良少年最爱看的漫画书里。
2. **受害者读取结算**：不良少年NPC在某天阅读这本漫画时，会在结算器中“拾取”到这个夹带物。
3. **强行改变社交拓扑**：由于 `CharacterAwareness` 系统的介入，不良少年的认知数据库会被强行注入“校花暗恋我”的虚假事实（虽然 `authenticity` 较低，但会影响其效用打分）。随后他的AI可能受此驱动，主动去找校花搭话甚至告白，从而引发全校关系网的蝴蝶效应。

### 3.4 NPC的漂流瓶目标链 (NPC Autonomous Interaction & Goal Chain)
当NPC在图书馆执行阅读行为时，有概率**自主发现**书中的漂流瓶/夹带物。一旦发现，系统将不再仅仅是静默的数据存储，而是会基于漂流瓶的内容与该NPC的性格特征，生成全新的**目标链 (Target Chain)**：

1. **传播与接力 (Propagate / Relay)**
   *   **触发条件**：NPC性格八卦，或阅读到具有话题性的“校园传闻”、“发泄涂鸦”时。
   *   **行为链**：NPC不仅不会销毁它，反而会在漂流瓶上追加自己的评论或线索，然后主动寻找下一本受众广的书籍（如《校报合集》或热门小说）将其重新夹入。这使得某些情报能在多本书籍中流动，甚至演化成全校性的都市传说。
2. **决策与行动 (Decision & Action)**
   *   **触发条件**：漂流瓶内容涉及该NPC的切身利益（如指向自己的情书、或者关于自己朋友的秘密），或涉及NPC极度感兴趣的解谜（Lore）。
   *   **行为链**：直接干涉NPC的效用打分系统。例如：收到伪造情书的NPC可能会生成 `Target_SeekCharacter` 寻找“发信人”确认心意；拾取到解谜残页的中二病NPC可能会生成 `Target_MoveTo` 前往旧校舍地下室进行探索。漂流瓶成为了剧情事件的“物理触发器”。
3. **销毁与清理 (Destroy / Discard)**
   *   **触发条件**：**所有NPC均可触发**。例如NPC认为漂流瓶的内容对自己毫无意义（效用打分极低），或者NPC将其视为单纯的垃圾；也包括特定身份（如风纪委员）将其视为违禁品，或普通NPC阅读到极度厌恶的内容等情况。
   *   **行为链**：NPC自主决定不再保留该物品，将生成 `Target_ThrowTrash` (丢弃垃圾) 目标，带着漂流瓶移动到垃圾桶所在地并将其彻底销毁。玩家如果想保护某条被发现的线索，甚至需要在此行为链完成前将其拦截。

## 4. 与现有源码架构的整合与挂载点 (Implementation API)

此案子完美契合 `DieLoli` 源码目录结构，只需在以下位置进行挂载开发：

1. **`Script/Config/config_def.py` 与配置读取**：
   * 在该文件中补充 `LibraryNoteConfig` 类，并在初始化模块中载入 CSV 配置表，供全局 `Cache` 调用。
2. **`Script/Design/settle_behavior.py` (结算器挂载)**：
   * 在 `handle_settle_behavior` 中拦截阅读事件的结束结算。
   * 新增方法 `def trigger_hidden_note_drop(character_id: int, book_id: int, now_time: int):`。
   * **好感与状态同步**：如果玩家阅读到了特定的夹带物，在此处直接复用源码中现成的 `change_character_social_now` 方法，改变相关的 `favorability`（好感度）和 `social_contact`（社交圈）。
3. **`Script/Core/game_type.py` (数据持久化)**：
   * 将 `HiddenNote` 类和 `CharacterAwareness` 的新增映射关系加入持久化存储，确保存档/读档（`save_handle.py`）时状态不丢失。
4. **`Script/Design/instruct/` (指令挂载)**：
   * 编写新增的玩家交互指令模块，例如 `instruct_library_search.py` 和 `instruct_library_plant.py`，配置对应的 UI Panel 输出，将查找到的 `Content_Template` 经 `text_handle` 格式化后显示给玩家。

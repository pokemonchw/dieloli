# 角色与数值系统 (Script/Design/character*.py)

在 DieLoli 中，角色（NPC和玩家）是世界的核心实体。由于游戏存在数千名独立演算的NPC，因此角色的对象化和数值框架设计的性能与扩展性极其重要。

## 1. 角色实体对象 (`character.py`)
所有的实体都会被实例化为 `Character` 类。它是一个庞大的数据载体，包含了角色的方方面面：
* **基础属性 (Attributes)**：力量、智力、魅力、体质等基础面板。
* **状态值 (Status)**：包含健康值、精神状态、饥饿度、水分、清洁度等动态数据（类似模拟人生）。
* **天赋与特质 (Talents & Traits)**：性格特点、各种能力修正。
* **行为缓存 (Behavior Cache)**：当前正在执行的任务/动作、目标的持续时间。
* **关系网 (Relationships)**：包含家庭树 (`FamilyIndex.json`)，好感度字典等。

## 2. 角色生命周期管理 (`character_handle.py`)
本模块是角色增删改查的入口：
* **生成与初始化**：NPC 生成时会根据设定的性别比例、教师/学生比例 (`game_path_config.py` 中的比例) 进行大批量生产。他们的名字通过 `NameIndex.json` 随机组合生成。
* **关系链构建**：生成时会连带生成其原生家庭结构（父母、兄弟姐妹），确保整个世界的社会关系在初始状态就是闭环的。

## 3. 数值结算与计算 (`attr_calculation.py`, `attr_text.py`)
由于复杂的增益、减益和装备效果，属性的最终值是动态计算的：
* **补正计算**：衣服属性、心情状态、临时 Buff 都会对角色的基础面板进行修正。
* **衰减与增长机制**：随着时间流逝（每刻/每小时），饥饿度、疲劳度会自动上升，当达到临界值时会触发强制性的生存行为（如去食堂吃饭或回宿舍睡觉）。

## 4. 服装与随身物品 (`clothing.py`)
为增加游戏深度，游戏自带了一套独立的服装管理逻辑。
* 支持多部位穿搭（内衣、外套、配饰等）。
* 服装不但提供属性加成，还具有特定的“性感值”、“暴露度”等特殊属性，这会严重影响该 NPC 在交互时其他角色的反应逻辑（由 StateMachine 进行判定）。
